# programmers-77484 기준 풀이

이 PR은 정답 코드만 비교하는 자료가 아닙니다. 제출을 끝낸 뒤 아래 순서로 비교하세요.

1. 본인 풀이의 상태 정의와 불변식을 한 문장으로 설명합니다.
2. 공식 풀이의 경계 조건이 본인 코드에서 빠졌는지 확인합니다.
3. 시간·공간 복잡도를 입력 상한에 대입합니다.
4. 다른 언어 풀이에서 구현 차이와 동일한 알고리즘 구조를 찾습니다.

## 문제 안내

# 로또의 최고 순위와 최저 순위

문제 원문과 입출력 제한은 [프로그래머스 77484](https://school.programmers.co.kr/learn/courses/30/lessons/77484)에서 확인하세요. 이 챌린지는 원문을 복제하지 않고 풀이의 근거를 묻습니다.

## 필요한 사전 개념

먼저 입력을 **의미별로 세는 상태**로 바꿉니다. 당첨 번호와 확정 일치하는 수, 아직 어떤 번호인지 모르는 수, 확정 불일치 수를 구분하세요.

## 제출 전 사고 질문

1. `lottos`의 각 값은 어떤 세 상태 중 하나인가요?
2. 최고 순위와 최저 순위에서 달라지는 값은 무엇이고, 끝까지 변하지 않는 값은 무엇인가요?
3. 일치 개수 0과 1이 같은 순위가 되는 경계를 수식이나 표로 표현해보세요.
4. 당첨 번호를 배열로 매번 찾는 풀이와 집합으로 바꾼 풀이의 복잡도를 비교하세요.

## 필수 반례

- 모든 번호가 0인 경우
- 0이 없고 당첨 번호와 하나도 일치하지 않는 경우
- 이미 여섯 번호가 모두 일치하는 경우

## 제출물

통과한 코드와 함께 `확정 일치`, `미확정`, `순위 변환`을 각각 한 문장으로 설명하세요. 반복문이 끝난 뒤 유지되는 불변식과 시간·공간 복잡도도 적어주세요.

- [ ] 복잡도 계산이 실제 반복/자료구조와 일치한다.
- [ ] 공식 코드와 다르더라도 불변식과 복잡도가 같으면 유효한 대안으로 남긴다.
