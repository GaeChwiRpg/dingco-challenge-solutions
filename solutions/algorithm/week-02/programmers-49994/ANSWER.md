# programmers-49994 기준 풀이

이 PR은 정답 코드만 비교하는 자료가 아닙니다. 제출을 끝낸 뒤 아래 순서로 비교하세요.

1. 본인 풀이의 상태 정의와 불변식을 한 문장으로 설명합니다.
2. 공식 풀이의 경계 조건이 본인 코드에서 빠졌는지 확인합니다.
3. 시간·공간 복잡도를 입력 상한에 대입합니다.
4. 다른 언어 풀이에서 구현 차이와 동일한 알고리즘 구조를 찾습니다.

## 문제 안내

# 방문 길이

문제 원문은 [프로그래머스 49994](https://school.programmers.co.kr/learn/courses/30/lessons/49994)에서 확인하세요.

## 풀이 관점

좌표를 정점, 한 번의 유효한 이동을 간선으로 보면 상태를 단순하게 정의할 수 있습니다. 이 문제는 방문한 **점**이 아니라 처음 지나간 **길**의 개수를 세어야 하므로, 양방향 이동을 같은 간선으로 표현하는 방법이 핵심입니다.

## 제출 전 사고 질문

1. A에서 B로 이동한 길과 B에서 A로 이동한 길을 같은 키로 만드는 방법은 무엇인가요?
2. 경계를 벗어난 명령이 현재 위치와 방문 집합을 모두 바꾸지 않아야 하는 이유는 무엇인가요?
3. 점 집합만 저장하면 틀리는 가장 작은 반례를 만드세요.
4. 좌표 네 개를 문자열, 튜플, 정수 인코딩으로 저장하는 방법을 비교하세요.

## 필수 반례

- 같은 길을 왕복
- 경계 밖 명령 뒤 다시 유효한 이동
- 서로 다른 길이 같은 도착점에 도달
- 빈 명령 또는 한 글자 명령

## 제출물

`현재 위치`와 `방향 없는 간선 집합`을 상태로 정의하고 각 명령 처리 후 유지되는 불변식, 시간·공간 복잡도를 적으세요.


## 공개 후 체크

- [ ] 복잡도 계산이 실제 반복/자료구조와 일치한다.
- [ ] 공식 코드와 다르더라도 불변식과 복잡도가 같으면 유효한 대안으로 남긴다.
