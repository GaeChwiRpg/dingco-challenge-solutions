# programmers-17677 기준 풀이

이 PR은 정답 코드만 비교하는 자료가 아닙니다. 제출을 끝낸 뒤 아래 순서로 비교하세요.

1. 본인 풀이의 상태 정의와 불변식을 한 문장으로 설명합니다.
2. 공식 풀이의 경계 조건이 본인 코드에서 빠졌는지 확인합니다.
3. 시간·공간 복잡도를 입력 상한에 대입합니다.
4. 다른 언어 풀이에서 구현 차이와 동일한 알고리즘 구조를 찾습니다.

## 문제 안내

# [1차] 뉴스 클러스터링

문제 원문은 [프로그래머스 17677](https://school.programmers.co.kr/learn/courses/30/lessons/17677)에서 확인하세요.

## 필요한 사전 개념

해시와 문자열 구현을 함께 사용합니다. 원문 문자열을 바로 비교하지 말고 대소문자와 유효 문자 규칙을 적용해 **비교 가능한 다중집합**으로 정규화하세요.

## 제출 전 사고 질문

1. 두 글자 중 하나라도 영문자가 아니면 왜 원소 전체를 버려야 하나요?
2. 일반 집합이 아니라 다중집합이어야 하는 반례를 만드세요.
3. 교집합과 합집합의 크기를 빈도수의 min/max로 계산하는 이유를 설명하세요.
4. 두 다중집합이 모두 비었을 때 별도 정의가 필요한 이유는 무엇인가요?

## 필수 반례

- 대소문자만 다른 문자열
- 같은 두 글자 원소가 반복
- 공백·숫자·특수문자가 두 글자 사이에 등장
- 두 다중집합이 모두 빈 경우

## 제출물

정규화 함수의 계약, 다중집합 연산, 정수 변환 시점과 버림 규칙을 설명하고 시간·공간 복잡도를 적으세요.


## 공개 후 체크

- [ ] 코드 없이 풀이를 먼저 설명할 수 있다.
- [ ] 최소·최대·중복·빈 경계를 직접 테스트했다.
- [ ] 복잡도 계산이 실제 반복/자료구조와 일치한다.
- [ ] 공식 코드와 다르더라도 불변식과 복잡도가 같으면 유효한 대안으로 남긴다.
