## 문제 안내

# 학습 크레딧 최소 조합

수료를 위해 정확히 `target`학점이 필요합니다. 신청 가능한 학습 모듈의 학점은 `credits`에 있고, 같은 종류의 모듈을 여러 번 신청할 수 있습니다.

정확히 `target`학점을 만드는 데 필요한 모듈 수의 최솟값을 반환하세요. 정확히 만들 수 없다면 `-1`을 반환합니다.

## 함수 계약

```text
minimum_modules(credits, target) -> integer
```

- `1 <= credits.length <= 20`
- `1 <= credits[i] <= 100`
- `1 <= target <= 10,000`
- 중복 학점 값이 들어올 수 있습니다.

## 예시

```text
credits = [2, 3, 5]
target = 11
answer = 3  # 3 + 3 + 5
```

```text
credits = [4, 6]
target = 7
answer = -1
```

## 제출 전 사고 질문

1. `dp[x]`를 어떤 값으로 정의하면 `dp[x-credit] + 1` 전이가 자연스러워지나요?
2. 같은 모듈을 여러 번 사용할 수 있다는 조건은 반복 순서에 어떤 영향을 주나요?
3. 큰 수 sentinel에 1을 더할 때 생길 수 있는 문제를 어떻게 피하나요?
4. 가장 큰 학점부터 고르는 그리디가 실패하는 반례를 만드세요.

## 제출물

초기값 `dp[0]`, 도달 불가능 상태, 전이식, 반환값을 설명하세요. 최소성에 대한 귀납적 근거와 `O(target * credits.length)` 복잡도를 적으세요.
