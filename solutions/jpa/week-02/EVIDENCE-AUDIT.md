# 증거 감사표

| 주장 | 필요한 원본 | 이 기준안의 판정 |
|---|---|---|
| 신규 save의 persist 경로 | 코드·테스트·원시 로그 중 해당 자료 | 자료와 결론이 직접 연결되어야 통과 |
| 분리 객체 save의 SELECT+merge 경로 | 코드·테스트·원시 로그 중 해당 자료 | 자료와 결론이 직접 연결되어야 통과 |
| 전달 객체와 반환 객체 비동일성 | 코드·테스트·원시 로그 중 해당 자료 | 자료와 결론이 직접 연결되어야 통과 |
| flush/commit 마커 로그 | 코드·테스트·원시 로그 중 해당 자료 | 자료와 결론이 직접 연결되어야 통과 |

## 리뷰 순서

1. 요구사항을 만족하는 파일이 실제 diff에 있는지 확인합니다.
2. 검증 명령과 실패 케이스가 재실행 가능한지 확인합니다.
3. 설명의 각 결론이 코드·테스트·로그 중 하나를 가리키는지 확인합니다.
4. 측정 범위를 넘어선 일반화와 만들어낸 수치를 제거합니다.
